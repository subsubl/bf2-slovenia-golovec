
Server System Requirements
==========================

These are some general guidelines for the minimum requirements for a server.

Linux & Windows
---------------

.. list-table:: Minimum Requirements
   :header-rows: 1

   * - Hardware
     - Minimum
     - Note
   * - CPU
     - 3Ghz Processor
     - PR (Project Reality) uses a lot of CPU, so get the fastest one you can afford.
   * - RAM
     - 2GB
     - You need at least 1GB per server instance plus an extra 1GB for overhead.
   * - Disk
     - 40GB
     - About 15GB for server files and installation, with more space needed for battlerecorder files.
