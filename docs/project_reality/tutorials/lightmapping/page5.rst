
Importing Statics into 3DsMax
=============================

The next step is to import static objects into 3DsMax.

#. Navigate to :menuselection:`BF2 --> Bf2 Lightmapping` and click :guilabel:`Load Staticobjects.con`.
#. Browse to your map's :file:`Staticobjects.con` file and open it.
#. Wait for the import to complete; the duration depends on the number and complexity of the objects.

.. image:: https://media.realitymod.com/tutorials/Adv_3DsMax_LMing/Adv_3DsMax_LMing_000029.jpg
   :align: center

.. image:: https://media.realitymod.com/tutorials/Adv_3DsMax_LMing/Adv_3DsMax_LMing_000030.jpg
   :align: center

Once the import is complete, the scene will be populated with static objects.

.. image:: https://media.realitymod.com/tutorials/Adv_3DsMax_LMing/Adv_3DsMax_LMing_000031.jpg
   :align: center

.. important::

   Save the 3DsMax scene, create a backup, and restart the computer before continuing.
