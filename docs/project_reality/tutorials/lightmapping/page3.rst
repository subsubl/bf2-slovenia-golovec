
3DsMax - Lightmapping Scene Setup
=================================

Create a new scene in 3DsMax. Navigate to :menuselection:`Customise --> Units Setup`. For lightmapping, set the :guilabel:`Display Unit Scale` to :guilabel:`Generic Units`. Then, click :guilabel:`System Unit Setup` and set :guilabel:`1 Unit` equal to "1.0 Inches". Click :guilabel:`Ok` to apply the changes. This sets the correct scale: **1 meter in BF2 equals 10 units in 3DsMax**.
