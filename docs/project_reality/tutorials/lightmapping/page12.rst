
Testing Light & Lightmap Settings
=================================

Before proceeding, render test lightmaps for several statics to verify that the settings are correct and functioning as expected.

Unhide your Overgrowth layer or objects. If they do not have the leaf material applied, apply it now, or at the very least, before rendering.

.. tip::

   Alternatively, you can freeze the layer. This has a similar effect to removing the material and can improve FPS.

.. image:: https://media.realitymod.com/tutorials/Adv_3DsMax_LMing/Adv_3DsMax_LMing_000194.jpg
   :align: center

Select a representative sample of objects for testing, such as:

* Large buildings with interiors.
* Objects that will have shadows cast on them by trees.
* Objects with point lights.
* Any objects where you are uncertain if the lightmap size is correctly set.

.. image:: https://media.realitymod.com/tutorials/Adv_3DsMax_LMing/Adv_3DsMax_LMing_000195.jpg
   :align: center

Navigate to :menuselection:`BF2 --> BF2 Lightmapping`. Set the folders where the tools will save the lightmaps:

Temp Folder
   This is where the lightmaps generated by 3ds Max will be stored. It is recommended to create a folder named :guilabel:`Temp` within your lightmapping scene folder.

Output Folder
   This is where the converted files will be saved.

.. image:: https://media.realitymod.com/tutorials/Adv_3DsMax_LMing/Adv_3DsMax_LMing_000196.jpg
   :align: center

.. image:: https://media.realitymod.com/tutorials/Adv_3DsMax_LMing/Adv_3DsMax_LMing_000197.jpg
   :align: center

.. image:: https://media.realitymod.com/tutorials/Adv_3DsMax_LMing/Adv_3DsMax_LMing_000198.jpg
   :align: center

.. image:: https://media.realitymod.com/tutorials/Adv_3DsMax_LMing/Adv_3DsMax_LMing_000199.jpg
   :align: center

With your test objects selected, click the :guilabel:`Render Selected Objects` button.

.. image:: https://media.realitymod.com/tutorials/Adv_3DsMax_LMing/Adv_3DsMax_LMing_000200.jpg
   :align: center

Once rendering is complete, you will have a set of :file:`.tga` files for each generated object LOD.

.. image:: https://media.realitymod.com/tutorials/Adv_3DsMax_LMing/Adv_3DsMax_LMing_000429.jpg
   :align: center

Next, convert these to :file:`.dds` so that BF2 can read them.

#. Locate the :file:`~convert.bat` file in your :file:`\\Autodesk\\3ds Max 9\\Scripts\\bf2` folder.
#. Open the file with a text editor.

   .. code-block:: text
      :caption: Example script content

      @echo off
      "E:\Program Files (x86)\Autodesk\3ds Max 9\scripts\bf2\bin\extern\nvdxt.exe" -file "F:\My Documents\3dsmax\scenes\Project Reality\Statics\Afghan Compound Buildings v3\LM_Tests\Renders\Temp\*.tga" -dxt1a -outdir "F:\My Documents\3dsmax\scenes\Project Reality\Statics\Afghan Compound Buildings v3\LM_Tests\Renders\Output"

#. Update the paths to match your environment. The first path should point to your 3ds Max 9 and PR:BF2 Max Tools installation. The second path (ending in :file:`\\Temp\\*.tga`) should point to your map's lightmaps ``Temp`` folder. The final path (ending in :file:`\\Output`) should point to your map's lightmaps output folder.

   .. warning::

      Avoid setting your output folder directly to your level's :file:`/lightmaps/objects/` folder to prevent accidentally overwriting existing lightmaps. It is safer to move them manually.

   .. code-block:: text
      :caption: Example of updated paths

      @echo off
      "E:\Program Files (x86)\Autodesk\3ds Max 9\scripts\bf2\bin\extern\nvdxt.exe" -file "F:\My Documents\3dsmax\scenes\Project Reality\LightMaps\Jamaica\Temp\*.tga" -dxt1a -outdir "F:\My Documents\3dsmax\scenes\Project Reality\LightMaps\Jamaica\Output"

#. Run the :file:`.bat` script. A :file:`cmd.exe` window will appear, displaying the conversion progress. This may take time depending on the number of files.

Once finished, browse to your map's lightmaps :guilabel:`Output` folder. You should see a set of :file:`.dds` images, one for each LOD of each static.

.. image:: https://media.realitymod.com/tutorials/Adv_3DsMax_LMing/Adv_3DsMax_LMing_000431.jpg
   :align: center

Copy these files into your :file:`\\pr_edit\\levels\\*YOUR MAP*\\Lightmaps\\Objects` folder, then load your map in the BF2 Editor to verify the lightmaps.

Examine the textures closely to ensure quality. Each lightmap channel has a specific purpose:

:Green: Sun
:Blue: Sky
:Red: Point

For example, in the first image showing a large building with trees, notice the subtle shadow around the small roof section on the top left. While barely noticeable in-game, these details contribute to visual realism.

Lessons Learned
---------------

Based on these tests, the following adjustments were made:

* Increased the lightmap texture size of :guilabel:`citybuilding_3a/b` from :guilabel:`128 64 32 16` to :guilabel:`256 128 64 32` to correct shadow errors.
* Increased the lighthouse's Omni Light multiplier from :guilabel:`1` to :guilabel:`2` to improve illumination.

Once you are satisfied with your light settings and test results, you can proceed to fully lightmap your objects.
